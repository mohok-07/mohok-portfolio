Selected Work — 01

FinRAG

A privacy-first AI terminal that turns dense financial documents into an instantly queryable database, with strict page-level citations.

Live Demo → View on GitHub

The Problem

Annual reports, pitch decks and financial filings can run into hundreds of pages. Reading all of it isn't realistic. Skimming it is risky — the number you needed is usually buried on page 140.

What I Built

FinRAG lets you ask a document a direct question and get an answer grounded in the page it actually came from — built around retrieval-augmented generation and designed to minimize hallucination through grounded, page-level citations rather than guesswork.
